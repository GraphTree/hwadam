# Hwadam HTML prototype

Electron 작업 공간의 화면 구조와 첫 예측 흐름을 검토하기 위한 로컬 HTML 프로토타입입니다. 설치, 빌드, 외부 서비스 없이 작동합니다.

## 실행

`index.html`을 브라우저로 열거나 저장소 루트에서 다음 명령으로 실행합니다.

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory prototype
```

http://127.0.0.1:4173 에 접속합니다. 현재 브라우저의 localStorage에 작업을 저장합니다. 브라우저/포트가 다르면 별도 상태를 사용합니다. 저장소 사용이 차단되거나 용량이 부족하면 화면에서 알립니다.

## 미리 구성된 내용

- 성수 리테일 랩의 가상 일별 판매 데이터: 2026-07-06 ~ 2026-09-27, 84일 × 3개 메뉴 = 252행.
- 입력 데이터셋 엔티티, 예측 결과 엔티티, 5개의 오퍼레이션.
- CSV 읽기 → 시계열 정규화 → 수요 예측 → 결과 CSV로 연결된 컴포지션.
- 발행된 설계 JSON, 예측 CSV, 실행 이력, 수요 예측 대시보드 앱.
- 실제 입력 및 결과 CSV 예시: `data/sample-sales.csv`, `data/sample-forecast.csv`.
- 설계 예시: `data/sample-composition.json`.

## 직접 해볼 흐름

1. **아티팩트 → CSV 업로드**에서 파일을 선택하거나 **가상 판매 데이터 사용**을 누릅니다. 날짜/시계열/수량 열을 매핑하고 등록합니다.
2. 아티팩트 상세에서 **컴포지션 만들기**를 누릅니다. 예측 템플릿 또는 빈 그래프로 시작할 수 있습니다.
3. 그래프에서 노드를 선택해 설정을 바꾸고, 기능을 추가/제거하거나 순서를 변경합니다. 이동 평균 변환을 추가하면 계산에도 반영됩니다.
4. **발행**하면 현재 설계를 별도의 JSON 아티팩트로 보관합니다. **실행**은 미발행 변경이 있으면 먼저 발행한 뒤 결과 CSV와 결과 엔티티 참조, 실행 이력을 만듭니다.
5. **결과 보기 → 앱 만들기** 또는 실행 완료 화면의 **앱 만들기**에서 대시보드를 등록합니다.
6. 앱에서 기간/모델/데이터 범위를 바꾸면 자동 재계산합니다. 빠른 연속 입력은 마지막 설정으로 실행됩니다. 메뉴 필터는 결과 표시만 바꿉니다.
7. 아티팩트/실행 상세에서 원본, 컴포지션, 고정된 설정, 결과로 이동합니다. CSV/JSON 파일을 내려받을 수 있습니다.

## 화면과 개념의 구분

`docs/architecture/CORE_CONCEPT.md`, `03_detailed_spec.md`, `02_software_architecture.md`, `00_vision.md`, `HANDOFF.md`와 후속 결정 문서를 바탕으로 구성했습니다.

- 핵심 메뉴: **앱 / 컴포지션 / 아티팩트**.
- 재사용 재료: **엔티티 / 오퍼레이션**. Node는 오퍼레이션의 별도 정의가 아니라 컴포지션 안의 배치이므로 그래프 안에서 편집합니다.
- 사용자 요청에 따라 컴포지션 발행 시 아티팩트 목록에도 설계 스냅샷(JSON)을 등록합니다. 컴포지션 자체의 ID/버전과 스냅샷 아티팩트 ID는 분리합니다.
- Entity는 이름 있는 참조, Entity Kind는 스키마, Artifact는 실제 데이터 또는 스냅샷입니다.
- Run은 노드 순서, 입력, 버전, 파라미터를 고정합니다. 앱은 원래 연결한 결과의 실행 그래프와 입력을 재사용하므로 이후의 미발행 그래프 편집이 앱 계산을 바꾸지 않습니다.

## 프로토타입의 범위

- 실제 Electron IPC, SQLite, AI 생성, 권한 격리, 임의 코드 실행은 구현하지 않습니다.
- 그래프는 포트 타입을 검증하는 **세로 자동 연결 방식**입니다. 자유 좌표 드래그, 분기, 임의 간선 편집, 중첩 컴포지션은 포함하지 않습니다. 같은 오퍼레이션은 한 번씩 배치할 수 있습니다.
- 모델은 마지막 7일을 반복하는 기준 모델과 직전 값을 유지하는 기준 모델입니다. 정확도 평가나 신뢰 구간을 주장하지 않습니다.
- CSV는 최대 2MB/10,000행, YYYY-MM-DD의 일 단위, 비어 있지 않은 시계열 이름, 0 이상의 수량, 시계열당 최소 7일 및 공통 마지막 날짜를 지원합니다. 중복/누락 날짜 및 잘못된 숫자는 등록 전에 안내합니다.
- 일 단위 가상 판매 수량과 메뉴별 데이터는 이번 디자인 검증을 위한 가정입니다.
- 개인 지식, 대화, 외부 연결 및 운영 수준의 실패/취소 실행 기록은 이번 요청의 화면 범위에 포함하지 않습니다.
- 가이드는 화면 왼쪽 아래에서 열 수 있습니다. 키보드 포커스, 폼 레이블, 반응형 레이아웃, 모달 취소, 빈 검색 결과 및 오류 상태를 포함합니다.

## 파일 책임

- `index.html`: 진입점. 외부 CDN/폰트/네트워크 의존성 없음.
- `styles.css`: 디자인 토큰, 화면/컴포넌트 레이아웃, 반응형 및 포커스 상태.
- `core.js`: 가상 데이터, CSV 파싱/정규화, 그래프 검증, 기준 예측, 버전/실행/아티팩트 생성.
- `app.js`: 해시 라우팅, 화면, 모달, 상호작용, 브라우저 저장.
- `core.test.js`: CSV 검증, 그래프 검증, 예측 결과, 계보 불변성 및 실패 시 원자성 검증.

Node 20 이상에서 `node --test prototype/core.test.js`로 테스트합니다. 브라우저 실행 자체에는 Node가 필요하지 않습니다.

## 검증 기록

- 데이터 계약/예측/계보/실패 처리 자동 테스트 8개 통과.
- 브라우저에서 CSV 파일 읽기, 열 매핑 오류 복구, 등록, 컴포지션 생성, 노드 추가/이동, 잘못된 포트 연결 차단, 발행/실행, 앱 생성, 자동 재계산을 확인했습니다.
- 1440px, 1024px, 390px 창 크기에서 확인했습니다.
